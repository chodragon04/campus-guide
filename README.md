# 과기대 캠퍼스 가이드

서울과학기술대학교 학생과 방문자를 위한 캠퍼스 안내 웹사이트입니다. (2026-2 웹프로그래밍 프로젝트)

- 홈페이지: https://chodragon04.github.io/campus-guide/

## 페이지

| 페이지 | 기능 |
| --- | --- |
| `index.html` | 오늘 날짜, 오늘 수업(강의실 → 지도 링크), 오늘의 학식 요약 |
| `map.html` | 카카오 지도에 건물 번호 핀 45곳, 핀을 누르면 건물 정보 창(카카오맵 길찾기 링크), 종류·편의시설 필터, `map.html?b=건물ID`로 특정 건물 열기, `map.html?edit=1` 좌표 수정 모드 |
| `buildings.html` | 건물 45곳 카드 목록, 이름·편의시설·부서 검색, 종류·편의시설 필터, 지도 바로가기 링크 |
| `food.html` | 생활관 요일별 식단(월~일), 학생식당 브랜드별 메뉴판, 테크노파크 주간 식단, 식당 위치 링크 |
| `timetable.html` | 개설 강좌 검색(서버 API), 시간표에 담기·빼기(시간 겹침 확인), 강의실 → 지도 링크, localStorage 저장 |

## 사용 기술

HTML, CSS, JavaScript(DOM, 이벤트), 카카오 지도 API, Geolocation API, localStorage, fetch(JSON), Node.js + Express(서버·API), GitHub Actions, GitHub Pages

## 서버 (Node.js + Express)

`server.js`가 사이트 파일(html, css, js, data)을 제공하고, 필요한 데이터만 골라 응답하는 API를 둡니다.

```
npm install
npm start          # http://localhost:3000
```

| API | 응답 |
| --- | --- |
| `GET /api/courses?q=검색어&limit=30` | 과목명·교수명 검색 결과(검색어로 시작하는 과목 우선)와 전체 결과 수 |
| `GET /api/courses/info` | 학기, 전체 강좌 수, 갱신 시각 |
| `GET /api/food` | 이번 주 학식 전체 |
| `GET /api/food?date=2026-11-11` | 그날 식단만 |

- 브라우저는 API를 먼저 부르고, 서버가 없는 곳(GitHub Pages)에서는 같은 내용의 `data/*.json`을 대신 불러온다.
- 저장소의 크롤러·설정 파일은 공개하지 않도록 `css/`, `js/`, `data/` 폴더와 html 파일만 제공한다.
- `data/*.json`이 바뀌면(Actions가 갱신) 다음 요청 때 다시 읽는다.

## 학식 자동 수집

`scripts/crawl-food.js`가 아래 세 곳에서 식단을 모아 `data/food.json`에 저장합니다. GitHub Actions(`.github/workflows/crawl-food.yml`)가 매일 06:00(한국 시간)에 한 번 실행하고, 바뀐 내용이 있으면 자동으로 커밋합니다. 브라우저에서 학교 사이트를 직접 불러오면 CORS로 막히기 때문에 이 방식을 사용합니다.

| 식당 | 출처 | 수집 방법 |
| --- | --- | --- |
| 생활관 KB학사·성림학사·수림학사 | 생활관 홈페이지 식당이용안내 | 주간 식단 표(`table.chang`)에서 날짜별 조식·중식·석식 추출 |
| 학생식당 ST:Table, ST:Dining | 학교 홈페이지 식단 메뉴가 연결한 노션 메뉴판 | 노션 공개 페이지 API로 브랜드·메뉴·가격 데이터베이스 조회 |
| 서울테크노파크 | 테크노파크 식단 게시판 | 최신 게시글의 주간 식단 이미지 주소 |

- 생활관 추가: `DORMS` 배열에 식당이용안내 탭 주소의 `foodtype` 값을 한 줄 추가
- 한 식당이 실패해도 나머지는 계속 수집하고, 실패한 식당은 지난번 데이터를 유지
- 수동 실행: GitHub 저장소의 Actions 탭 → "학식 크롤링" → Run workflow

> 학교 홈페이지의 옛 학식 페이지에는 더 이상 식단이 올라오지 않아서, 학교가 현재 안내하는 식단 출처를 직접 분석해 크롤러를 작성했습니다.

## 개설 강좌 자동 수집

`scripts/crawl-courses.js`가 수강신청시스템의 시간표 조회 화면(로그인 불필요)과 같은 요청을 보내 이번 학기 주간·야간 전체 강좌를 받아 `data/courses.json`에 저장합니다. GitHub Actions(`.github/workflows/crawl-courses.yml`)가 매주 월요일 06:30(한국 시간)에 실행합니다.

- 조회 화면은 표를 그릴 때 `/JSONMain`에 조회 조건을 JSON으로 보내 강좌 목록을 받는다. 먼저 조회 화면을 열어 세션 쿠키를 받아야 요청이 성공한다.
- 조회 가능한 학기는 조회 화면의 `maxYmst` 값에서 자동으로 읽는다.
- 강의 시간 `"수(3 ~ 4), 목(3)"`은 요일·시작 교시·끝 교시로 나눠 저장한다.
- 내 시간표는 서버에 저장하지 않고 각자 브라우저의 localStorage에만 저장한다.

## 건물 데이터

`data/buildings.json`에 캠퍼스 건물·장소 45곳을 정리했습니다. 건물 번호는 1~64번이지만 중간 번호(9, 15~29, 48~50 등)는 쓰이지 않습니다.

| 항목 | 출처 |
| --- | --- |
| 건물 번호·이름, 층 구성 | 학교 홈페이지 캠퍼스지도의 건물 목록과 건물별 안내, 캠퍼스맵 PDF(2024)의 건물번호순 목록 |
| 입주 대학·대학원, 행정 부서, 복지시설(카페·매점·식당·은행 등) | 캠퍼스지도의 "대학 / 대학원 / 행정지원 / 복지시설" 분류 목록 |
| ATM·증명서 발급기·식당·카페 위치 | 캠퍼스맵 PDF의 "교내 편의시설" 목록 |
| 좌표(위도·경도) | 카카오 지도 API의 장소 검색(`서울과학기술대학교 + 건물명`) |
| 종류(강의동·생활관·학생 편의·행정·산학·기타) | 직접 분류 |

- 카카오 장소 검색에 없는 3곳(무궁관-A, 어의천, 남문)은 지도 그림 위치로 대략 넣은 뒤, 지도의 좌표 수정 모드(`map.html?edit=1`)에서 실제 위치를 직접 확인해 고침
- 식당 위치: 생활관 식당은 각 학사 건물, ST:Table은 학생회관(제1학생회관), ST:Dining은 제2학생회관
- 강좌 데이터의 강의실 표기와 맞추기 위해 다른 이름을 `aliases`에 기록 (예: 청운관(북관), Techno Cube(테크노 큐브), 도예실습실)

## 폴더 구조

```
css/     공통·페이지별 스타일
js/      공통·페이지별 스크립트
data/    건물, 학식, 강좌 JSON 데이터
scripts/ 학식·강좌 크롤러 (Node.js)
server.js Express 서버와 API
.github/ GitHub Actions 설정
images/  이미지
```
